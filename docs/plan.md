概要設計は [design.md](design.md)、実装設計は [architecture.md](architecture.md)。
タスクの実体はGitHub issue（ラベル `M0:基盤`〜`M3:検証`）。ここは全体像だけ。

最終更新: 2026-07-27

## 方針

- **両OS同時開発（KMP + CMP）、動作検証はAndroid実機優先**。iOSはスパイク（#3）以外は後追い確認
- 実装順は決定事項どおり：**土台 → 謎解き → シナリオ**。このプランは土台までをカバーし、
  謎解き以降はM3の検証結果を見てから切る
- 天候は**プロバイダ選択制**（Open-Meteo／OpenWeatherMap／Visual Crossing。既定はキー不要のOpen-Meteo）
- LLMは**Anthropic／OpenAIの2フォーマットのみ実装**し、ベースURL・モデル名・キーは自由設定
  （OpenAI互換エンドポイント対応）。初回セットアップで疎通確認まで必須
