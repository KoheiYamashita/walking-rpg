# walking-rpg （仮）

> 相棒と一緒に、歩いて街を育てる。何も失わない。
> その上に、生成されたシナリオが乗る一話完結RPG。

現実の街を舞台にした、**戦闘のない**位置情報RPG。

歩いた場所が育ち、そこに生き物が戻ってくる。パートナーAIが同行し、
LLMが生成したシナリオを一緒にクリアしていく。

## 特徴

- **減衰も罰もない** — 歩いたら必ず前進する。久しぶりに開いてもブランクに一切言及しない
- **狭い行動範囲が有利** — 同じ場所に通い続ける人が強い設計（既存の位置ゲーとの最大の差別化）
- **戦闘を作らない** — 敵＝到達すべき場所＋必要な歩数。「強い敵」＝遠い／長い
- **シナリオはLLM生成** — OSMの地物を材料に、その人の街の実際の地形を使った物語をつくる
- **パートナーAI** — 責めない、催促しない。犬の散歩モデル

## 構造

| 層 | 内容 | 性質 |
|---|---|---|
| 土台 | 街を育てる（成長・図鑑・振り返り） | 永続。飽きても残る |
| 上物 | 章立てのシナリオRPG | 消費コンテンツ。無限生成 |
