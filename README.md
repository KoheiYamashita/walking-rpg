# walking-rpg （仮）

> 相棒と一緒に、歩いて街を育てる。何も失わない。
> その上に、生成されたシナリオが乗る一話完結RPG。

現実の街を舞台にした、**戦闘のない**位置情報RPG。
歩いた道が育ち、そこに生き物が戻ってくる。減衰も罰もない。
同じ場所に通い続ける人が強い設計（既存の位置ゲーとの最大の差別化）。
